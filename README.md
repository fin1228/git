## 使用方式

克隆到本地：

```bash
git clone https://github.com/fin1228/git.git
cd git
```

## 提交规范

建议使用 [Conventional Commits](https://www.conventionalcommits.org/zh-hans/) 风格：

- `feat: 新增功能`
- `fix: 修复缺陷`
- `docs: 文档变更`
- `refactor: 重构`
- `chore: 构建/工具类杂项`
